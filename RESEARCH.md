# Research Document - SKIIN Landing Page Refinement

## Context Summary

The user has identified several critical issues with the current SKIIN landing page implementation that need to be addressed:

1. **Care360 Technology Messaging**: Current tone is too technical/revolutionary. Should focus on home-based medical Holter study convenience.
2. **Missing Section**: "Why SKIIN Leads in Cardiac Monitoring" section is not appearing (possible font color issue).
3. **Redundant Components**: Multiple similar sections need consolidation (Why SKIIN Leads, Advanced Myant Technology, From Sensor to Solution).
4. **Design Philosophy**: Preference for fewer, more convincing modern components with images over many icon-based similar components.
5. **Real-time ECG Badge**: Currently disappearing, needs to be preserved.

### Primary Goals:
1. Rework Care360 copy to emphasize home-based medical Holter study
2. Fix visibility of "Why SKIIN Leads in Cardiac Monitoring" section

- Use existing visual assets effectively

## Research Findings

### Modern Health Tech Design Patterns:
1. **Hero Features**: Large visual sections with minimal text
2. **Interactive Reveals**: Information layered behind hover/click
3. **Visual Storytelling**: Images drive narrative, text supports
4. **Benefit Clustering**: Group related benefits into unified experiences

### Effective Medical Device Marketing:
1. **Convenience First**: Emphasize ease of use and home comfort
2. **Clinical Credibility**: Show process and results
3. **Technology Secondary**: Features support benefits, not lead
4. **Trust Building**: Real people, real scenarios
