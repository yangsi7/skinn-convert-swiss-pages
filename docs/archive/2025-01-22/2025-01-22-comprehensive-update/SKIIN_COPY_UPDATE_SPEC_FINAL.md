## 10. Content Governance

### Update Triggers

Any of these events trigger a content review:
- New clinical evidence published
- Regulatory changes
- Insurance policy updates
- Competitor launches
- User feedback patterns
- Conversion rate changes >10%

### Review Cycles

**Weekly**: A/B test results and quick wins
**Monthly**: Full content audit and updates
**Quarterly**: Strategic messaging review
**Annually**: Complete overhaul assessment

### Approval Matrix

| Content Type | Approver | SLA |
|--------------|----------|-----|
| Medical claims | Medical Director | 48h |
| Legal disclaimers | Legal Counsel | 72h |
| Patient testimonials | Marketing + Legal | 24h |
| Pricing changes | CEO | 24h |
| General copy | Marketing Manager | 4h |

### Version Control

All copy updates follow semantic versioning:
- **Major** (X.0.0): Complete rewrite or rebranding
- **Minor** (1.X.0): New sections or significant updates
- **Patch** (1.0.X): Small fixes or optimizations

Example: 3.2.1 = Third major version, second feature update, first bug fix

### Documentation Requirements

Every copy change requires:
1. Update in main copy document
2. Translation flag for other languages
3. Git commit with clear message
4. Entry in change log
5. Stakeholder notification if major
