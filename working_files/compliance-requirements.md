# Compliance Requirements - SKIIN Switzerland

## Overview
SKIIN must meet stringent Swiss and EU regulations for medical devices, data protection, and healthcare marketing. This document outlines all compliance requirements based on the NEW-WEBSITE-UPDATE-SPECS.md.

## Medical Device Compliance

### Swissmedic Requirements
1. **Device Classification**
   - SKIIN Holter: Class IIa medical device
   - Requires Swissmedic registration
   - CE marking must be displayed

2. **Required Notices**
   ```
   SKIIN is a Class IIa medical device per EU MDR
   CE ##### | Swissmedic Registration: CH-#####
   Manufactured under ISO 13485:2016
   ```

3. **Marketing Restrictions**
   - No direct-to-consumer promotion of prescription devices
   - Must emphasize "prescription required"
   - Cannot make unrestricted health claims

### Medical Disclaimers
**Required on every page:**
```
Medical Disclaimer: SKIIN is a prescription medical device intended 
for use under the supervision of a healthcare professional. The 
information on this website is for educational purposes only and 
does not replace professional medical advice, diagnosis, or treatment.
```

**Specific Warnings:**
- Not for emergency use
- Not real-time monitoring
- Contraindications (pacemaker patients)
- Age restrictions (18+ unless specified)

## Data Protection Compliance

### Swiss Federal Data Protection Act (FADP/DSG)
1. **Privacy Policy Requirements**
   - Clear data collection purposes
   - Data retention periods
   - User rights (access, deletion, portability)
   - Data processor information
   - Cross-border transfer notices

2. **Consent Management**
   - Explicit consent for health data
   - Granular consent options
   - Withdrawal mechanism
   - Consent logging

3. **Data Security**
   - Encryption requirements (in transit/at rest)
   - Access controls documentation
   - Breach notification procedures
   - Data minimization principle

### GDPR Alignment
- Privacy by design
- Data protection officer contact
- Rights to rectification
- Right to be forgotten
- Data processing agreements

## Healthcare Marketing Compliance

### Swiss Therapeutic Products Act (TPA)
1. **Advertising Restrictions**
   - No exaggerated claims
   - Evidence-based statements only
   - Balanced benefit/risk presentation
   - Clear prescription requirement

2. **Required Information**
   - Intended use statement
   - Contraindications
   - Manufacturer details
   - Vigilance reporting

### Content Guidelines
**Permitted:**
- Educational content about heart health
- Process explanations
- Insurance information
- Physician resources

**Prohibited:**
- Direct product promotion to patients
- Comparative claims without evidence
- Guarantees of outcomes
- Testimonials implying guaranteed results
